# Desafio Backend Developer - Eduardo Xavier

## Estrutura

- part1.js - Busca de cidade por CEP
- part2.js - Rota mais barata entre dois CEPs (Dijkstra)
- cidades_cep.txt - Arquivo de entrada de exemplo para Parte 1
- rota.txt - Arquivo de entrada de exemplo para Parte 2

## Como executar

Requer Node.js instalado.

node part1.js
node part2.js

Cada script lê seu respectivo arquivo .txt no mesmo diretório.

## Tecnologia

- Node.js (testado em v25.9.0)
- Sem dependências externas
